# Путь в профессию

Комплект встречи для фестиваля «Наука 0+». Аудитория — школьники 5–11 классов.

Сквозная формула: **Хочу · Могу · Умею · Надо**.

Формат: яркая презентация с иллюстрациями и спокойный рассказ ведущего. Интерактивов немного, и они явно помечены: формула, тест ДДО Климова, кейс, письмо себе.

## Файлы для проведения

| Файл | Зачем |
| --- | --- |
| `materials/Путь_в_профессию_сценарий_60_минут.docx` | Сюжет на час |
| `materials/Путь_в_профессию_сценарий_20_минут.docx` | Отдельный сюжет на 20 минут |
| `materials/Путь_в_профессию_презентация_60_минут.pptx` | 21 слайд с изображениями |
| `materials/Путь_в_профессию_презентация_20_минут.pptx` | 11 слайдов |
| `materials/Путь_в_профессию_раздаточный_материал.docx` | Тетрадь: формула, ДДО, направления, поддержка, письмо |

Направления высшего образования в материалах: социология (39.03.01), социальная работа (39.03.02), политология (41.03.04), организация работы с молодёжью (39.03.03).

Пересобрать комплект: `python3 materials_src/build.py`.
