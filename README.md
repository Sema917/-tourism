# Путь в профессию

Комплект встречи для фестиваля «Наука 0+». Аудитория — школьники 5–11 классов. Версия `2026.2`.

## Порядок встречи

1. Кейс «Точка выбора»
2. Короткая информация
3. Интерактив 1 — разведка для кейса
4. Информация про «надо» и маршруты
5. Интерактив 2 — **Хочу · Могу · Умею · Надо**
6. Формула типов профессий (Климов) + тест ДДО
7. Направления и поддержка (просто)
8. Сборка кейса
9. Письмо себе

На слайдах — понятный школьникам язык. Подробности приёма и полный список мер — в тетради.
