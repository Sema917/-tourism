# Путь в профессию

Комплект встречи для фестиваля «Наука 0+». Аудитория — школьники 5–11 классов. Версия `2026.7` — **экспресс 20 минут**.

Сценарий — дословный текст ведущего (простые реплики, без лозунгов).

## Порядок встречи (20 минут)

1. Смысл «пути в профессию» и карта встречи  
2. **Хочу · Могу · Умею · Надо** (графы в раздатке)  
3. Четыре направления подготовки — обзор и **подробные карточки**  
4. **Опросник Климова** — 15 пар **на слайдах** со стикерами (ответ в раздатке)  
5. Ключ  
6. **Подробный разбор пяти типов** (после опроса)  
7. Шаг на месяц  

## Раздатка

Одна страница A4:
- графы метода «хочу — могу — умею — надо»
- опросник на 15 вопросов по методике Климова
