# Путь в профессию

Комплект встречи для фестиваля «Наука 0+». Аудитория — школьники 5–11 классов.

Сквозная формула: **Хочу · Могу · Умею · Надо**. В обеих версиях есть сокращённый опросник Е. А. Климова (ДДО), кейс «Точка выбора» и четыре направления высшего образования: социология (39.03.01), социальная работа (39.03.02), политология (41.03.04), организация работы с молодёжью (39.03.03).

## Файлы для проведения

| Файл | Зачем |
| --- | --- |
| `materials/Путь_в_профессию_сценарий_60_минут.docx` | Сюжет на час: опорный текст, тайминг, развилки по возрасту, ключ, запасные ходы к кейсу |
| `materials/Путь_в_профессию_сценарий_20_минут.docx` | Отдельный сюжет на 20 минут, не ускоренное чтение часового |
| `materials/Путь_в_профессию_презентация_60_минут.pptx` | 30 слайдов, заметки в режиме докладчика |
| `materials/Путь_в_профессию_презентация_20_минут.pptx` | 12 слайдов |
| `materials/Путь_в_профессию_раздаточный_материал.docx` | Одна тетрадь на обе встречи: формула, опросник, ключ, направления, поддержка, письмо себе из будущего |

Тетрадь печатают на каждого участника (А4, можно чёрно-белую) и не собирают. На часовой встрече отвечают на вопросы 1–15, на короткой — только на вопросы с пометой «экспресс» (1–10). Ключ открывают по слову ведущего «считаем».

Пересобрать комплект: `python3 materials_src/build.py`.
