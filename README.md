# Путь в профессию

Комплект встречи для фестиваля «Наука 0+». Аудитория — школьники 5–11 классов. Версия `2026.3`.

## Порядок встречи

1. Кейс «Помогите Лере выбрать» (выдаём в начале, решаем в конце)
2. Карта инструментов
3. Интерактив 1 — сбор фактов о Лере
4. Информация про «надо» и маршруты
5. Интерактив 2 — **Хочу · Могу · Умею · Надо** (формула выбора человека)
6. **Формула профессии по Климову** — предмет, цели, средства, условия + пять типов (**это не тест**)
7. **Тест ДДО** — отдельно: к какому типу дел тянет участник
8. Направления подготовки (социология, социальная работа, политология, организация работы с молодёжью) + поддержка
9. Решение кейса по 4 пунктам
10. Письмо себе

## Три разных инструмента

| Инструмент | О чём |
| --- | --- |
| Хочу — могу — умею — надо | Формула выбора **человека** |
| Формула профессии | Как описать **работу**: предмет, цели, средства, условия |
| Тест ДДО | Гипотеза интереса к типу дел (не описание профессии) |
