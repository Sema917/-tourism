# Путь в профессию

Комплект встречи для фестиваля «Наука 0+». Аудитория — школьники 5–11 классов. Версия `2026.4` — **экспресс 20 минут**.

## Порядок встречи (20 минут)

1. Смысл «пути в профессию» и карта встречи  
2. **Хочу · Могу · Умею · Надо** (графы в раздатке)  
3. Пять типов по Климову + **четыре направления подготовки**  
4. **Опросник Климова** — 15 пар  
5. Ключ, связь с формулой/направлениями, шаг на месяц  

## Раздатка

Одна страница A4:
- графы метода «хочу — могу — умею — надо»
- опросник на 15 вопросов по методике Климова
