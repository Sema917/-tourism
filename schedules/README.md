# График работы лифтов

Файл `График_работы_лифты.docx` — расписание на 3 недели для двух лифтов и трёх работников.

## Условия

- **Лифт А** — график 2/2 (два рабочих / два выходных)
- **Лифт Б** — график 5/2 (пять рабочих / два выходных)
- Каждый работник за 3 недели: **2 недели 2/2** и **1 неделя 5/2**
- На каждом лифте каждый день должен быть сотрудник; пустая ячейка — законный выходной (для резолюции)

## Ротация

| Неделя | Лифт Б (5/2) | Лифт А (2/2) |
| --- | --- | --- |
| 1 | №1 | №2 и №3 (противофаза) |
| 2 | №2 | №1 и №3 (противофаза) |
| 3 | №3 | №1 и №2 (противофаза) |

Лифт А закрыт все дни. Лифт Б пуст по Сб–Вс (выходные 5/2).

Пересобрать: `python3 schedules/build_schedule.py`.
